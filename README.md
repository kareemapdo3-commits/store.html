# store.html ⚡ متجر ديجيتال
منصة عربية لبيع وشراء المنتجات الرقمية (قوالب، كورسات، ملفات صوتية، كتب إلكترونية، وغيرها) بواجهة عصرية بتصميم زجاجي (Glassmorphism) ودعم كامل للغة العربية واتجاه الكتابة من اليمين إلى اليسار (RTL).
المشروع عبارة عن ملف HTML واحد يحتوي على الواجهة والتنسيق والمنطق البرمجي، بدون أي مكتبات خارجية أو خطوات بناء.
✨ المميزات
🏠 صفحة رئيسية مع قسم بطل (Hero)، التصنيفات، المنتجات المميزة، وإحصائيات المتجر
🔍 بحث فوري في المنتجات من شريط التنقل أو من الصفحة الرئيسية
🗂️ تصفية حسب التصنيف: برمجة، تصميم، صوتيات، فيديو، كتب إلكترونية
📄 صفحة تفاصيل المنتج مع التقييمات والمنتجات المشابهة
🛒 سلة شراء مع التحكم في الكمية والحذف وحساب الإجمالي
👤 تسجيل حساب وتسجيل دخول وصفحة ملف شخصي
📤 رفع منتج جديد مع صورة اختيارية للمنتج
📦 سجل الطلبات في الملف الشخصي
💾 حفظ تلقائي للبيانات في المتصفح (localStorage)
📱 تصميم متجاوب يعمل على الجوال والتابلت والحاسوب
🔔 إشعارات منبثقة (Toast) وتأثيرات حركية سلسة
